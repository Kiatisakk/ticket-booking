Term Project 
1. Scope 
The Ticket Booking System is a web-based application that allows users to browse events (movies, 
concerts, seminars), select specific seats at specific showtimes, make payments, and generate tickets. 
The system supports role-based access control with Admin, Staff, and Customer roles. 
2. Requirement Analysis 
2.1 User Management 
Objective 
Provide a secure registration and authentication system that allows users to create accounts, log in, and 
access the ticket booking platform with appropriate role-based permissions. 
Requirement 
Description 
User Registration 
New users shall create an account by providing full name, email, and 
password. The system shall auto-assign the "Customer" role. 
User Login 
Registered users shall log in using email and password. The system shall 
validate credentials and issue a session token. 
Password Security 
Passwords shall be stored using hashing  to prevent plain-text storage. 
Role-Based Access Control 
The system shall support three roles: Admin, Staff, and Customer with 
different permission levels. 
Session Management 
Sessions shall use JWT tokens with a configurable expiration period 
(default: 7 days). 
Email Uniqueness 
Each email address can only be registered once to prevent duplicate 
accounts. 
Password Validation 
Passwords must meet a minimum length requirement (at least 6 
characters). 
User Role Assignment 
One role can be assigned to many users, but each user must have exactly 
one role.

2.5 Double-Booking Prevention 
Objective 
Ensure the same seat cannot be booked more than once for the same showtime, preventing conflicting 
reservations. 
Functional Requirements 
Requirement 
Description 
Seat Availability Check 
The system shall verify seat availability before creating a booking. 
Atomic Booking Creation 
If any requested seat is already booked, the entire booking request shall 
fail. 
Booked Seat Indication 
The seat map shall visually indicate which seats are already booked. 
Showtime Seat View 
The system shall maintain a view of all seats per showtime, indicating 
availability status and calculated seat price. 
Venue consistency check 
Before inserting booking details, the system shall validate within the same 
transaction that the selected seat belongs to the same venue as the 
referenced showtime (Seats.VenueID = Showtimes.VenueID). 
  
Business Rules 
Rule 
Description 
Seat unavailable 
A seat is considered unavailable if a BookingDetail already exists for the 
same showtime and is linked to a Completed booking, or to a Pending 
booking whose ExpiresAt has not passed. Cancelled bookings and expired 
pending bookings release the seat back to available. 
All-or-nothing 
If any requested seat is unavailable during the transactional recheck, the 
entire booking request shall fail. 
Seat availability source 
Seat availability and pricing shall be queried from the 
ShowtimeAvailableSeats view filtered by ShowtimeID. 
Transactional recheck 
Before inserting booking details, the system shall recheck existing active 
bookings for the same (ShowtimeID, SeatID) within a transaction. 
 
2.6 Booking Lifecycle and Session Timeout 
Objective 
Bookings have a limited time window to complete payment. Unpaid bookings expire and release seats 
back to available inventory. 
Functional Requirements 
Requirement 
Description 
Auto-set Expiry 
All bookings shall be created with an expiration time of 15 minutes from 
creation. 
Expired Booking Rejection 
The system shall reject payment attempts for expired bookings. 
Status Transition 
On successful payment, booking status shall change from Pending to 
Completed. 
Showtime-Based Booking Deadline 
The system shall prevent users from creating a new booking if the 
showtime's StartDateTime has already passed. 
Expired Seat Release 
The system shall treat expired pending bookings as inactive so their seats 
become available again. 
   
Business Rules 
Rule 
Description 
15-minute window 
ExpiresAt = NOW() + 15 minutes 
Expired pending release 
Pending bookings whose ExpiresAt has passed are treated as inactive for 
seat availability and cannot be paid.
